# Лабораторная работа №2. ONVIF
## Инструкция по работе
1. Установить [Python](https://www.python.org/) версии 3.10 либо выше. Тестирование производилось на версии 3.12.4.
2. Установить нужные библиотеки, выполнив в корневой папке проекта команду:
```
pip install -r requirements.txt
```
3. Запустить файл main.py при помощи интерпретатора Python открытием из проводника либо при помощи команды:
```
python3 main.py
```
4. В графическом интерфейсе ввести данные для подключения к камере и нажать кнопку "Подключиться". Удостовериться по выводу программы, что подключение произошло успешно.
5. В графическом интерфейсе ввести данные поворота и приближения для камеры и нажать кнопку "Применить". Удостовериться по выводу программы, что применение новых значений произошло успешно.
