# 121. Виртуальная студия
## Описание проекта
Технология позволяет производить рендеринг виртуального пространства в NDI потоки, а также автоматически настраивать поворот виртуальных камер в соответствии с данными, полученными с реальных ONVIF PTZ-камер.
## Требования
1. Установить NDI 6 Runtime
2. Установить Godot Engine 4.4 Mono
## Инструкция по запуску прототипа
1. Запустить Godot Engine
2. Открыть проект
3. Разместить в сцену структуру следующего вида при необходимости добавления новой виртуальной камеры
* SubViewport
  * NDI Output
  * Camera3D
    * OnvifCameraHookNode
Если OnvifCameraHookNode отсутствует в дереве нод, необходимо включить плагин OnvifCameraHook в настройках проекта (Project > Project Settings > Plugins) путём переключения флажка (чекбокса) в активированное положение.
4. Расположить камеру в сцене
5. Если нужно выводить данные с камер в NDI потоки из редактора, следует:
* Установить для SubViewport значение Render Target > Update Mode в Always 
* Для NDI Output перевести Enable Editor Output во включенное положение
6. При необходимости произвести дополнительную настройку сцены, добавить нужные объекты и скрипты
7. Ввести в OnvifCameraHookNode камер данные для подключения к ONVIF-камерам при необходимости получения данных о их положении
8. Запустить проект
Проверку вывода можно осуществить с помощью NDI Studio Monitor.
